Configurações

Informe onde a API está rodando para preparar suas consultas.

As configurações são salvas no arquivo config.json do Explorer. As consultas usam os dados da API configurada.

Conexão com a API

Se a API estiver neste computador, use o endereço local e a porta configurada nela. Exemplo: http://localhost:8080. Informe apenas o endereço base, sem /v1/companies.
segundos
Quanto tempo aguardar pela resposta da API. O padrão é 30 segundos.
